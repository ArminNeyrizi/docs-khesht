# مستندات نظام مدیریت یکپارچه خشت

این مخزن، منبع مستندات فارسی نظام مدیریت یکپارچه (IMS) هلدینگ خشت است.

- [درگاه اصلی مستندات](https://khesht.gitbook.io/khesht-docs/)
- [اسناد چارچوب IMS در مخزن](./docs/ims/README.md)
- [مستندات اجرایی در GitBook](./documentation/README.md)

**وضعیت:** چارچوب اولیه در حال بازبینی مدیریت است. این مستندات به‌تنهایی اثبات‌کننده انطباق با استاندارد یا اخذ گواهینامه نیستند.

مستندات رسمی باید مالک، وضعیت تصویب، نسخه و شواهد لازم را داشته باشند. اطلاعات محرمانه مالی، قراردادی، پرسنلی و پروژه‌ای را در این مخزن عمومی منتشر نکنید.
