# نظام مدیریت یکپارچه خشت

**سامانه مدیریت و بهبود عملیات هلدینگ خشت**

این درگاه، مرجع مستندات نظام مدیریت یکپارچه خشت است: از تعیین حدود اختیار و طراحی فرایند تا کنترل کیفیت، مدیریت ریسک، شاخص‌های عملکرد و بهبود مستمر.

> **وضعیت:** چارچوب اولیه در مرحله بازبینی مدیریت است. این وب‌سایت به‌تنهایی اثبات‌کننده انطباق با استاندارد یا اخذ گواهینامه نیست.

## حوزه‌های اصلی

- **حاکمیت:** مسئولیت‌ها، تصمیم‌ها و حدود اختیار
- **فرایندها:** نقشه فرایندها، مالکیت و کنترل‌های اجرایی
- **خدمات مهندسی:** از احراز صلاحیت فرصت تا تحویل و اختتام پروژه
- **عملکرد:** تعریف شاخص‌ها، کیفیت داده و بازنگری نتایج
- **ریسک و بهبود:** ارزیابی ریسک، ممیزی، عدم انطباق و اقدام اصلاحی
- **اطلاعات مستند:** کنترل نسخه، تصویب، دسترسی و نگهداری سوابق

## چرخه عملیاتی

**الزام را مشخص کن → مسئول را تعیین کن → کار را اجرا کن → شاهد را ثبت کن → نتیجه را ارزیابی کن → اقدام اصلاحی را پیگیری کن**

## قواعد استفاده

1. نسخه‌های دارای وضعیت «پیش‌نویس» برای اجرای رسمی مصوب نیستند.
2. هر کنترل باید مالک، زمان اجرا و شاهد قابل بررسی داشته باشد.
3. حدود اختیار باید از ماتریس مصوب تفویض اختیار استخراج شود، نه از برداشت شخصی از عنوان شغلی.
4. شاخص بدون فرمول، منبع داده و مالک مشخص، مبنای قابل اتکای تصمیم نیست.
5. اطلاعات محرمانه مالی، قراردادی، پرسنلی و پروژه‌ای نباید در مستندات عمومی منتشر شود.

## شروع کار

از بخش «نظام مدیریت یکپارچه» در منوی بالا شروع کنید. اسناد اجرایی پس از بازبینی و تصویب مرجع مجاز، وضعیت مصوب خواهند گرفت.
